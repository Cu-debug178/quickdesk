# QuizDesk 云服务器部署指南（学生开发者标准方案）

架构：**轻量云服务器 + nginx（静态+反代） + Node 零依赖后端 + JSON 数据文件**。
不用买数据库，不用 Docker，一台最低配服务器全搞定。

## 0. 需要准备什么

| 东西 | 说明 | 花费 |
|---|---|---|
| 云服务器 | 腾讯云/阿里云「轻量应用服务器」，选 Ubuntu 22.04/24.04，最低配（2核2G）够万人级刷题 | 学生/新用户约 ¥60~120/年，可先蹲免费试用 |
| 域名（可选） | 不买就用 `http://服务器IP` 直接访问 | ¥10~50/年 |
| ICP 备案（可选） | 只有绑域名走国内加速才需要，控制台免费办理，1~2 周 | 免费 |

## 1. 购买服务器后（3 分钟）

1. 控制台记下**公网 IP**，重置或记下 root 密码
2. 控制台「防火墙」放行 **80 端口（TCP）**（腾讯云轻量默认已放，检查一下）

## 2. 上传项目（2 分钟）

本地执行（把整个 quizdesk 目录传上去）：

```bash
scp -r quizdesk root@服务器IP:/root/
```

## 3. 一键部署（1 分钟）

```bash
ssh root@服务器IP
bash /root/quizdesk/deploy/deploy.sh
```

脚本会自动：装 Node 和 nginx → 复制程序到 /opt/quizdesk → 生成随机管理令牌 → 注册 systemd 开机自启 → 配置 nginx。结束时会打印**访问地址、管理后台和令牌**，记下来。

## 4. 日常使用

- 刷题网址：`http://服务器IP/`
- 更新题库：浏览器打开 `http://服务器IP/admin.html` → 输入令牌 → 上传新 JSON → 即时生效（不用重启、不用重新部署）
- 数据备份：`tar czf backup.tar.gz /opt/quizdesk/server/data`（题库+错题都在里面）
- 服务状态：`systemctl status quizdesk`；看日志：`journalctl -u quizdesk -f`

## 5. 以后绑域名（可选）

1. 买域名 → 控制台提交 ICP 备案（免费，1~2 周）
2. 备案通过后把 `/etc/nginx/sites-available/quizdesk` 里 `server_name _;` 改成你的域名，`systemctl reload nginx`
3. 想要 HTTPS：`apt install certbot python3-certbot-nginx && certbot --nginx -d 你的域名`（Let's Encrypt 免费）

## 6. 常见问题

- **打不开**：90% 是云控制台防火墙没放行 80 端口
- **题库更新没生效**：管理后台保存即生效；浏览器强刷（Ctrl+Shift+R）
- **换服务器迁移**：新机器跑同样脚本 + 恢复 data 目录即可
